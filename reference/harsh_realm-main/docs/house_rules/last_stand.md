# Last Stand House Rule

## Overview

In solo play, the standard XWN dying rules are replaced with a Last Stand mechanic. When the player character reaches 0 HP, instead of immediate death, they get one final action before collapsing.

## Trigger

The Last Stand activates when the player's HP drops to 0 or below during combat.

## Procedure

1. Narrate the dramatic moment: the player is gravely wounded but not yet dead.
2. The player selects one of the following actions:
   - **Attack** — Make one attack with a -2 penalty to the roll. If this kills the last enemy, the character survives at 1 HP.
   - **Use [item]** — Use a consumable item (typically a healing item). If HP rises above 0, the character stabilizes and combat continues.
   - **Flee** — Attempt to escape. The flee always succeeds but is always messy (no skill check). The character escapes but may lose an item or take a parting blow (at GM discretion, automatic in solo play).

## Outcomes

| Action | Result if Successful | Result if Failed |
|--------|----------------------|-----------------|
| Attack | Enemy dead → survive at 1 HP | No enemies killed → character dies |
| Use item | HP > 0 → stabilize, continue combat | HP still ≤ 0 → character dies |
| Flee | Always escape (messy) | N/A — flee always succeeds |

## Notes

- The Last Stand can only trigger once per combat. If the character is healed and then drops to 0 again, they die immediately (no second Last Stand).
- Warriors with the Veteran's Luck ability may use it during Last Stand if it has not been expended.
- The -2 attack penalty on Last Stand attacks stacks with all other modifiers.
