## Summary

Implemented log filter functionality for the debug overlay in the Bevy client. The filter allows filtering logs by level (DEBUG, INFO, WARN, ERROR) and by category keywords.

## Implementation Details

### Structure: `DebugLogFilter`

Located in [crates/outpost-client/src/main.rs](../crates/outpost-client/src/main.rs#L57-L76)

```rust
#[derive(Resource, Clone)]
struct DebugLogFilter {
    pub show_debug: bool,
    pub show_info: bool,
    pub show_warn: bool,
    pub show_error: bool,
    pub category_filter: String,
}
```

**Features:**

- Individual toggles for each log level (DEBUG, INFO, WARN, ERROR)
- Substring-based category filtering (case-sensitive)
- Implements `Clone` for resource mutation via UI
- Defaults to showing all levels with empty category filter

## API / Usage

### Default Behavior

```rust
let filter = DebugLogFilter::default();
// Shows: all DEBUG, INFO, WARN, ERROR logs
// Category: "" (empty, shows all)
```

### Custom Filter

```rust
let mut filter = DebugLogFilter::default();
filter.show_debug = false;     // Hide DEBUG logs
filter.category_filter = "building".to_string();  // Show only "building" logs
```

### Apply to Log Entry

```rust
// Example: Check if log should be displayed
fn should_display_log(log_level: LogLevel, log_category: &str, filter: &DebugLogFilter) -> bool {
    // Check level
    let level_match = match log_level {
        LogLevel::Debug => filter.show_debug,
        LogLevel::Info => filter.show_info,
        LogLevel::Warn => filter.show_warn,
        LogLevel::Error => filter.show_error,
    };
    
    // Check category (substring match)
    let category_match = if filter.category_filter.is_empty() {
        true
    } else {
        log_category.contains(&filter.category_filter)
    };
    
    level_match && category_match
}
```
